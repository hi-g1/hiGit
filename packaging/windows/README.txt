hiGit 시험판 (Windows x64)
==========================

설치 파일(추천): hiGit_*_x64-setup.exe
  더블클릭하면 관리자 확인 없이 지금 사용자에게만 설치됩니다(한국어·English).
  지울 때는 설정 → 앱 → hiGit → 제거. 폴더 오른쪽 클릭 메뉴도 함께 지워집니다.

설치 없이: higit.exe를 더블클릭하세요.

"Windows의 PC 보호" 경고가 뜨면
  서명하지 않은 시험판이라 뜹니다. "추가 정보" → "실행"을 누르세요.

필요한 것
- Windows 10(1809 이상) 또는 Windows 11, 64비트
- WebView2 런타임: Windows 11에는 기본으로 들어 있고, 설치 파일은 없으면 내려받아 설치합니다.
  설치 없이 쓸 때 Windows 10에서 창이 뜨지 않으면 Microsoft "WebView2 Evergreen Bootstrapper"로 설치하세요.
  https://developer.microsoft.com/microsoft-edge/webview2/
- Git for Windows 2.30 이상: https://git-scm.com/download/win
  (없으면 앱이 시작할 때 안내합니다)
- Visual C++ 재배포 패키지는 필요 없습니다.

폴더 오른쪽 클릭 메뉴
  처음 켜면 탐색기에서 폴더를 오른쪽 클릭했을 때 "Git으로 관리"가 생깁니다.
  Windows 11은 "더 많은 옵션 표시" 안에 있습니다. 설정 "일반"에서 끌 수 있습니다.
