hiGit 시험판 (Windows x64)
==========================

실행: higit.exe를 더블클릭하세요. 설치하지 않고 바로 실행됩니다.

필요한 것
- Windows 10(1809 이상) 또는 Windows 11, 64비트
- WebView2 런타임: Windows 11에는 기본으로 들어 있습니다.
  Windows 10에서 창이 뜨지 않으면 Microsoft "WebView2 Evergreen Bootstrapper"로 설치하세요.
  https://developer.microsoft.com/microsoft-edge/webview2/
- Git for Windows 2.30 이상: https://git-scm.com/download/win
  (없으면 앱이 시작할 때 안내합니다)
- Visual C++ 재배포 패키지는 필요 없습니다.

"Windows의 PC 보호" 경고가 뜨면
- 서명하지 않은 시험판이라 뜹니다. "추가 정보" → "실행"을 누르세요.

라이선스
- 앱에 포함된 글꼴의 라이선스는 THIRD_PARTY_NOTICES.md에 있습니다.

문제가 있으면 저장소의 Issues에 알려 주세요.
