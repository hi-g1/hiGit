# 디자인 규칙 (Design)

방향: **담백하고 깔끔하게.** 틀은 무채색이고 주 버튼은 흑연색 채움이다. 파랑은 선택·포커스·링크에만 쓰고, 그 밖의 색은 브랜치 선·파일 상태·위험 작업처럼 뜻이 있을 때만 쓴다(D-026). 그림자·그라데이션·이모지·과한 둥근 모서리를 쓰지 않는다. "AI가 만든 템플릿" 느낌의 원인(보라-파랑 그라데이션, 큰 카드 그림자, 의미 없는 아이콘 남발, 모든 곳에 둥근 배지, 괄호로 덧붙인 설명)을 피한다.

브랜치 그래프 선 색은 채도를 낮춘 6색을 순서대로 쓴다(`--graph-1`~`--graph-6`): 라이트 `#3A6EA5`, `#2F7D4F`, `#9A6110`, `#7A5BA6`, `#2E7F86`, `#8A5A44`, 다크 `#7FA7D6`, `#6BBF8A`, `#D9A54A`, `#B59AE0`, `#5FBCC4`, `#C9967A`(D-094). 두 모드 모두 `--bg`·`--surface`에서 3:1 이상(그래픽 기준)이고 글자에는 쓰지 않는다. 현재 브랜치는 색이 아니라 "지금 여기" 표시와 굵기로 구분한다.

브랜치마다 색은 `src/features/branches/color.ts`의 `branchColor(이름, 기본 브랜치)` 하나로 정한다. 기본 브랜치는 `--graph-1`, 나머지는 이름 해시로 `--graph-2`~`--graph-6`이라 같은 브랜치는 어느 화면에서나 같은 색이다. 상단 바 브랜치 단추의 점, 브랜치 목록의 점, 홈 노선도의 선과 역이 이 함수를 쓴다. 글자에는 쓰지 않는다(D-031).

## 글꼴
- 본문: **Pretendard** (한글·영문 균형, OFL 라이선스, npm 패키지로 앱에 포함, D-014). 대체: `system-ui`.
- 코드·해시·파일 경로: **JetBrains Mono** (OFL, latin 부분만 포함, D-014). 한글은 Pretendard로 이어 받고, 그다음 대체는 `ui-monospace`.
- 크기: 13px(기본), 12px(보조), 15px(화면 제목, 시작 화면 상태 문장), 20px(시작 화면 처음 실행 제목, 홈의 버전 이름 칸 `--font-size-name`), 26px(시작 화면 프로젝트 이름, `--font-size-display`). 줄 간격 1.5.
- 굵기는 400과 600 두 가지만. JetBrains Mono는 400만 포함한다(D-014).

## 배치
- 작업 공간은 상단 바 + 2단이다(D-025).
- 상단 바 왼쪽은 프로젝트 메뉴와 브랜치 단추, 오른쪽은 동기화·버전 기록·작업 내역(D-045, D-058, D-085). 버전 기록과 작업 내역은 `--text-muted` 글자 버튼이고 켜져 있으면 굵게. 컨트롤은 5개 이하. 아이콘만 있는 버튼에는 툴팁. 합치는 중에는 브랜치 단추 대신 이름 글자만 두고 오른쪽 컨트롤을 숨긴다.
- 상단 바 바로 아래에 알림 줄이 쌓인다(아래 "알림 줄").
- 왼쪽 칸은 280~340px로 버전 이름 칸과 고친 파일 목록. 오른쪽 칸은 나머지 폭으로 비교 보기와 맨 아래 줄(아래 "비교 칸 아래 줄").
- 칸 사이는 간격 없이 `--border` 1px 선으로 나눈다. 작업 공간의 칸에는 둥근 모서리와 그림자를 쓰지 않는다.

## 간격과 모양
- 간격 단위 4px: 4, 8, 12, 16, 24, 32.
- 모서리: 버튼·입력 6px, 떠 있는 패널 8px. 원형은 아바타만.
- 그림자: 떠 있는 것(메뉴, 대화상자, 툴팁)에만 `0 4px 16px rgba(0,0,0,.08)`.
- 아이콘: Lucide, 16px, 선 굵기 1.5. 글자 없이 아이콘만 있는 버튼에는 반드시 툴팁.

## 부품 규칙
- **버튼**: 화면마다 주 버튼은 하나(`--primary` 채움, 글자 `--primary-text`). 나머지는 테두리 버튼 또는 글자 버튼. 글자 버튼은 본문색(`--text`)이고 파랑이 아니다.
- **위험 버튼**: `Button`의 `danger` 변형은 `--deleted` 채움에 글자 `--on-deleted`(600)이고, 되돌릴 수 없는 일의 확인 대화상자에서만 쓴다(고친 것 버리기, 멈춘 작업 정리, 강제로 멈추기). 대화상자를 여는 단추는 테두리 버튼이나 옅은 글자이고 위험 색을 채우지 않는다(고친 것 버리기만 호버 때 글자가 `--deleted`).
- **확인 대화상자**: 떠 있는 판(`--surface`, `--radius-panel`, `--shadow-float`, 뒤는 `--overlay`), 폭 440px까지. 제목 15px(600)에 무엇을 하는지 짧은 문장, 그 아래 대상 파일 이름을 코드 글꼴 12px `--text-muted`로. 오른쪽 아래에 위험 버튼과 주 버튼 "닫기"(주 버튼은 안전한 쪽, TrustDialog 방식).
- **체크 상자·입력칸**: 테두리 `--border-strong`. 체크 상자 켜짐은 `--primary` 채움.
- **Term 툴팁**: 지연 400ms, 위쪽 우선. 내용 세 줄: 원래 이름(600) · 명령(모노) · 설명(muted).
- **목록 행**: 높이 32px, 호버 시 `--surface-hover`, 선택 시 왼쪽 2px `--accent` 막대.
- **상태 표시**: 색만으로 알리지 않고 글자나 기호를 함께 쓴다(추가 `+`, 삭제 `−`, 파일 상태 이름).
- **빈 상태**: 그림 대신 한 줄 설명과 버튼 하나, 왼쪽 정렬.
- **굵은 글자 버튼**: 테두리 없이 600 굵기. 옆에 단축키를 `--text-muted` 12px 코드 글꼴로(시작 화면 상단 바의 "폴더 열기 Ctrl+O", D-033).
- **버전 이름 칸**: 파일 목록 위에 테두리 없는 큰 글자(600)로 이름, 바로 아래 설명(D-044). placeholder는 제안 이름과 "설명 추가"(`--text-muted`). 포커스는 `--accent` 밑줄 2px. 오른쪽 아래에 옅은 `Ctrl+Enter`와 주 버튼.
- **토스트**: 바로 한 일의 결과를 화면 아래 가운데에 8초 띄운다(D-042). 주 버튼과 같은 `--primary` 바탕에 `--primary-text` 글자(r-saved.png), 떠 있는 그림자. 결과 문구 + 굵은 글자 버튼("되돌리기") + 옅은 단축키. 마우스를 올리면 멈춘다. 한 번에 하나.
- **홈 노선도**(D-046, D-060): 상단 바 아래 두 줄. 위가 기본 브랜치, 아래가 지금 브랜치이고 갈라진 곳에서 꺾인다. 지금 브랜치가 기본 브랜치이거나 갈라지지 않았으면 한 줄. 선 굵기는 기본 브랜치 3, 지금 브랜치 4. 역은 `--surface`로 채우고 브랜치 색 테두리, 지금 버전 역만 크게. "지금 여기"는 `--primary` 바탕 작은 이름표. 줄 옆 글자(브랜치 이름, 고친 파일 수)는 `--text`·`--text-muted`. 그리기는 버전 기록 그리기 계층의 `layout`·`SvgRenderer`를 쓴다(architecture.md).
- **버전 기록 노선도**(r-log.png, D-087~D-092): 창 전체 폭 목록, 행 48px, 아래 `--border` 1px 선. 왼쪽 그래프 칸(레인 간격 24px, 첫 레인 x 40, 폭 240px까지) 오른쪽에 이름(`--text`, 말줄임) 옆으로 옅은 " · 안 올림"·" · 태그"·" · ● 브랜치"(12px `--text-muted`, 점만 브랜치 색), 작성자 90px, 날짜 90px 오른쪽 정렬, 오른쪽 여백 32px. 고른 행은 `--surface-hover` 바탕(r-log). 역은 `--surface` 채움에 레인 색 테두리, 합치기 버전은 큰 점, 지금 위치는 `--text` 바깥 고리, 접힌 구간은 작은 마름모와 "버전 N개 · 펼치기"(`--text-muted`). 목록 자체가 포커스를 받고(포커스 표시는 안쪽 `--accent` 2px) 고대비에서는 선·점이 `CanvasText`. 여러 역 선택(D-106): Shift+↑↓·Shift+클릭으로 지금 브랜치 선 위의 이어진 구간만 고른다(곁가지 행은 건너뜀). 고른 구간의 행은 `--surface-hover` 바탕과 왼쪽 2px `--accent` 막대, 글자 선택으로 번지지 않는다. 기록 정리할 수 있는 구간(모든 버전 보기, 2~50개, 합친 버전·첫 버전 없음)이면 머리에 글자 버튼 "N개 선택 · 기록 정리". Esc는 열린 메뉴 → 구간 → 홈 순서로 닫는다.
- **역 메뉴**(r-log.png, D-092): 고른 역 오른쪽에 떠 있는 판(`--surface`, `--shadow-float`, 폭 220px 이상). 항목 줄 13px, 강조 `--surface-hover`, 쓸 수 없는 항목은 `--text-muted`와 툴팁의 까닭(키보드로 그 항목에 닿아도 뜬다. 골라도 닫히지 않는다). "더 보기"는 선(`--border`) 아래, 그 묶음에 항목이 있을 때만. 비모달이라 목록을 스크롤하면 닫힌다. 역을 마우스 오른쪽으로 눌러도 그 역을 골라 연다(웹뷰 기본 메뉴는 뜨지 않는다).
- **브랜치 목록 팝오버**(D-047): 브랜치 단추 아래에 떠 있는 판(`--surface`, `--shadow-float`). 맨 위 찾기 칸, 아래 로컬·원격 묶음. 줄마다 색 점 + 이름 + 오른쪽에 맡긴 파일 수 같은 숫자. 고르면 묻지 않고 바로 갈아탄다. 찾는 이름이 없으면 Enter로 그 이름의 새 브랜치를 만든다. 찾기 칸이 비어 있으면 목록 아래 위 선(`--border`)으로 나눈 칸에 테두리 버튼 "main에 합치기"(D-071)나 "겹침 해결"(D-083)이 있다. 로컬 줄 오른쪽에는 호버·포커스·고른 줄에서만 보이는 작은 `…`(28px, `--text-muted`)가 있고 그 메뉴에 "브랜치 이름 바꾸기"·"브랜치 지우기"(D-103). 지금 브랜치와 기본 브랜치의 지우기는 흐리고 까닭은 툴팁. 이름 바꾸기는 그 줄이 `--accent` 테두리 입력칸이 되고(Enter로 확정, Esc는 그만두기만), 이름 안내는 아래 `--text-muted` 한 줄. 지우기는 확인 창 없이 하고 토스트의 되돌리기로 되살린다.
- **합치기 제안**(r-mergehint, D-048, D-049): 홈 노선도 줄 오른쪽 블록(폭 40%까지, 오른쪽 정렬). 굵은 글자(600) "main에 새 버전 N개", 그 아래 테두리 버튼 "main 가져와 합치기"(`<Term id="merge" />` 툴팁, 이 화면의 주 버튼은 버전 저장이라 채우지 않는다). 겹친 파일이 있으면 그 아래 `--text-muted` 12px "겹친 파일 N개"(툴팁에 5개까지). 좁으면 말줄임으로 노선도와 겹치지 않는다.
- **동기화 버튼**(D-045, D-080): `--border-strong` 테두리 버튼에 굵은 `<Term id="sync" />`와 옅은 ↑N·↓N(12px). 고친 파일이 없고 주고받을 것이 있으면 주 버튼으로 채운다. 도는 동안 "동기화 중 · N초", 3초 뒤 옆에 글자 버튼 "취소", 마지막 출력 뒤 30초가 넘으면 "응답 없음 · N초"(`--text-muted` 12px). 겹친 파일 글자는 `--deleted` 12px, 원격 확인 실패는 `--modified` 6px 점과 툴팁.
- **알림 줄**: 상단 바 아래 전체 폭 한 줄. `--surface-sunken` 바탕, `--text-muted` 12px 글자, 아래 `--border` 1px 선, 오른쪽에 테두리 버튼 하나. 위에서부터 감시 꺼짐("다시 읽기"), 멈춘 로컬 쓰기("응답 없음 · N초" · "강제로 멈추기", D-080), 끝나지 않은 작업("멈춘 작업 파일 N개" · "정리하기", "남은 맡겨 둔 파일 N건" · "복구하기", 다른 도구의 작업은 단추 없음, D-082) 순서로 쌓는다. 끝나지 않은 작업 줄만 글자 버튼 "닫기"가 있고 닫으면 이번 실행 동안 다시 보이지 않는다. 오류 줄(`ErrorNotice`)은 `--surface` 칸에 왼쪽 2px `--deleted` 띠와 "자세히 보기", 비밀 파일 알림 줄(이름 칸 아래, D-077)은 같은 꼴에 왼쪽 띠 `--modified`.
- **이름 대화상자**(계획 008 E23): 역 메뉴의 태그·여기서 새 브랜치. 확인 대화상자와 같은 판(폭 440px, `--overlay` 뒤). 제목(15px 600), 아래 `--text-muted` 한 줄에 역의 짧은 해시·이름, 입력칸 하나(포커스가 바로 감, Enter로 만들기, 한글 조합 중 Enter는 무시), 이름 안내는 `--text-muted` 12px, core 오류는 `--deleted` 12px 한 줄로 대화상자 안에. 태그는 그 역에 붙은 태그 목록과 줄마다 글자 버튼 "지우기". 아래 오른쪽에 "닫기"(글자)와 주 버튼 "만들기". 열린 동안 키는 뒤로 가지 않는다(전역 단축키가 돌지 않음). 마지막 버전 고치기는 같은 판을 560px로 넓혀 입력칸 대신 글상자(높이 160px 이상, 첫 줄이 이름)에 전체 메시지를 채우고, 넣은 파일이 있으면 `--text-muted` 한 줄 "넣은 파일 N개 함께 들어가요", 주 버튼 "고치기"(Ctrl+Enter도 같음)는 바뀐 것이 없으면 꺼진다.
- **이때 파일 보기**(D-105): 같은 판을 960px·높이 640px까지. 제목 아래 짧은 해시·이름, 그 아래 `--text-muted`로 작성자·날짜. 왼쪽 260px 파일 목록(상태 글자 `+`·`−`·`~`·`→`는 `--text-muted` 코드 글꼴, 고른 줄은 왼쪽 2px `--accent` 막대와 `--surface-hover`), 합친 버전이면 목록 위에 "합치기 전 버전과 비교" 한 줄, 500개를 넘으면 아래 "파일 N개 더". 오른쪽은 홈의 비교 보기 그대로(그 버전 안의 비교). ↑↓로 파일, Esc로 닫기. 900px 이하에서는 목록이 위(160px), 비교가 아래.
- **기록 정리 카드 지도**(D-106, 그림 없음, 노선도와 같은 느낌): 머리 줄(56px)은 왼쪽 `<Term id="rebase-i">`(제목)와 글자 버튼 "← 버전 기록"(Esc도), 오른쪽 글자 버튼 "원래대로"와 주 버튼 "정리하기"(바뀐 것이 없거나 막혔으면 꺼짐). 본문은 왼쪽 정렬 한 열(폭 560px까지), 왼쪽 1px `--border-strong` 선이 카드를 꿴다. 카드는 `--surface` 채움·`--border` 테두리·높이 72px 이상, 위 줄에 짧은 해시(코드 글꼴 12px `--text-muted`)·이름(말줄임, `<bdi>`)·"N개 묶음"·상태 글자("옮김"·"묶임"·"빠짐", `--text-muted`), 아래 줄에 작성자·날짜, 그 아래 글자 버튼 "위로"·"아래로"·"아래 카드와 묶기"(묶인 카드는 "묶기 풀기")·"빼기"(빠진 카드는 "넣기")·"메시지 고치기"(묶음의 맨 아래 카드만). 빠진 카드는 이름에 취소선과 `--text-muted`, 묶인 카드는 아래 카드와 간격 없이 붙고 사이 테두리는 점선. 고른 카드는 왼쪽 2px `--accent` 막대. 메시지는 카드 안 글상자(Esc·Ctrl+Enter로 닫기). 이름 앞의 손잡이(⋮⋮, `--text-muted`)를 끌면 놓을 자리 카드 위에 2px `--accent` 선이 보이고 끄는 카드는 옅어진다(놓으면 묶음째 옮김, 끄는 중 Esc는 취소, 끌기는 순서만 바꾼다). 막혔으면 손잡이가 없다. 막힌 까닭은 위에 왼쪽 2px `--deleted` 막대의 한 줄, 카드는 읽기만. 옛 버전을 가리키게 될 이름표가 있으면 `--text-muted` 한 줄로 수만. 아래 줄 `--surface-sunken` 바탕에 "정리 후 N개 · 빠지는 버전 M개 · 합쳐지는 버전 K개".
- **충돌 해결 화면**(D-028, D-086): 윗줄에 "● 합칠 브랜치 → ● 내 브랜치"와 "충돌 N곳 중 M곳 남음", 오른쪽에 글자 버튼 "합치기 그만두기"(늘 보임)와 모두 골랐을 때만 주 버튼 "합치기 마치기". 왼쪽 220px 파일 목록(✓·●, 선택 막대는 `--text`), 오른쪽에 경로·줄 번호, 질문(15px 600), 위아래 카드 둘. 이 화면의 색은 `branchColor`의 예외로 고정한다: 내 브랜치 `--graph-2`, 합칠 브랜치 `--graph-1`. 카드 왼쪽 3px 띠와 색 점은 그 색, 코드 바탕은 `--conflict-ours-bg`·`--conflict-theirs-bg`, "저장될 모습"의 줄 바탕도 고른 쪽 바탕(맥락 줄은 `--text-muted`, 직접 고친 줄과 원래 코드는 `--surface-sunken`). 고른 카드의 "이걸로"와 고른 "둘 다 쓰기"·"직접 고치기"는 `--primary` 채움, 나머지는 테두리. `--accent`는 쓰지 않는다. 고르지 않은 카드는 글자를 `--text-muted`로. 앱이 시작한 다른 작업도 같은 화면이고 카드 이름과 단추 문구만 바뀐다(D-101): 이 버전만 복사하기는 "내 브랜치"·"복사할 버전"과 "복사 마치기"·"복사 그만두기", 되돌리기는 "내 브랜치"·"되돌린 모습"과 "되돌리기 마치기"·"되돌리기 그만두기", 기록 정리는 "옮기는 버전"·"앞서 정리한 기록"(용어 없음)과 "기록 정리 마치기"·"기록 정리 그만두기". 색은 쪽을 뜻하므로 그대로(내 쪽 `--graph-2`). 기록 정리는 마친 뒤 다음 버전에서 다시 겹치면 토스트 없이 다음 충돌이 열린다.
- **작업 내역**(D-085, 세이브 카드): 창 전체 폭. 맨 위 한 줄 "되살려도 지금 버전은 남아요"(`--text-muted`), 아래 날짜별 묶음(묶음 제목 `--text-muted` 12px 600)의 카드(높이 56px 이상, 왼쪽 3px 띠 `--border-strong`). 카드: 시각(`--text-muted` 12px) · 제목(앱 작업은 `<Term>`, 그 밖은 원천 이름. 아래에 브랜치·백업 이름을 `--text-muted` 12px) · 버전 이름 · 오른쪽 테두리 버튼("이 시점으로 되돌리기" 또는 "꺼내기"). reflog의 Git 원문은 "자세히 보기"로 접는다. 되돌린 작업은 글자를 `--text-muted`로. 백업 이름은 아는 것이면 용어와 브랜치 이름("브랜치 지우기 · 기능")으로 보이고 원문 이름은 툴팁에, 모르는 이름은 그대로. "이 시점으로 되돌리기" 옆에 글자 버튼 "새 브랜치로"(이름 대화상자를 연다, 서명이 맞지 않는 줄에는 둘 다 없다). 맨 아래 글자 버튼 "로그 폴더 열기".
- **비교 칸 아래 줄**(r-mergehint, D-074, D-076): 비교 보기 맨 아래 한 줄(`--surface`, 위 `--border` 1px 선). 왼쪽에 글자 버튼 "임시 보관"과 "임시 보관 N개"(누르면 위로 뜨는 목록: 브랜치·시각·파일 수와 "꺼내기". 고친 파일이 있으면 "꺼내기"는 꺼지고 툴팁으로 까닭), 오른쪽 끝에 옅은 글자 "고친 것 버리기"(`--text-muted`, 호버하면 `--deleted`). 버리기 확인 대화상자는 "확인 대화상자" 규칙대로 파일 이름과 경로, 위험 버튼 "버리기"와 주 버튼 "닫기".
- **흐린 줄**: 투명도를 쓰지 않고 글자를 `--text-muted`로 바꾼다(대비 테스트가 투명도를 계산하지 못한다).
- **움직임**: 150ms ease-out, 페이드와 4px 이동만. `prefers-reduced-motion`이면 끈다.

## 문구 (D-027, D-024)
- 괄호로 덧붙이는 설명을 쓰지 않는다. 예: "합치기 그만두기 (원래대로)" → "합치기 그만두기".
- 버튼은 한 가지 동작을 동사로 끝나는 짧은 말로 쓴다. 목적어는 붙여도 된다(예: "폴더 열기").
- 보충 설명은 `<Term>` 툴팁, 일반 툴팁, 또는 둘째 줄로 보여준다.
- 존댓말 해요체로 통일한다. 합쇼체("~합니다")를 섞지 않는다.
- 한 낱말은 한 기능에만 쓴다. 예: "가져오기"는 pull에만, "원격 확인"은 fetch에만(D-059).
- 용어 호버 설명은 동작이면 "~하기", 대상이면 명사로 끝낸다. "~않음·~함·~사라짐" 같은 메모체를 쓰지 않는다. 주의할 내용은 둘째 문장에 "~요"로 쓴다.
- `src/messages/copy-rules.test.ts`가 괄호, 옛 용어, 합쇼체를 확인한다.

## 시작 화면 색 (D-031)
- 큰 노선도("마지막으로 하던 곳")의 선과 점만 브랜치 색(`--graph-*`). 노선도 옆 글자("지금 여기", 브랜치 이름, 버전 이름)는 `--text`·`--text-muted`로 쓴다(다크에서 그래프 색은 글자 대비에 못 미친다).
- 작은 노선도(목록 줄)는 `--border-strong`, 갈라진 브랜치만 `--text-muted`. 이름 칸(200px)과 상태 사이에 240×28px, 선 2px, 역 반지름 3.5.
- 큰 노선도는 높이 104px, 너비는 칸 너비(1100px까지), 기본 브랜치 줄이 아래(y 76)·갈라진 줄이 위(y 36), 역 이름은 갈라진 줄 위, "지금 여기"는 끝 역 아래. 모자라면 오래된 역을 "…"로 접는다(홈과 같은 배치 함수, D-090).
- 상태 글자는 `--text`이고 충돌만 `--deleted`.

## 확인 사항
- Windows(WebView2)와 Ubuntu(WebKitGTK)에서 글꼴 렌더링과 스크롤바 모양을 매번 비교한다. 스크롤바는 CSS로 얇게 통일.
- 한글 입력: 버전 저장 메시지 입력창에서 조합 중 Enter가 저장을 실행하지 않게 `isComposing`을 확인한다.
- Windows 고대비(WebView2의 `forced-colors: active`)에서 주 버튼·체크 상자가 보이는지 확인한다. WebKitGTK는 GTK 고대비 테마를 웹 내용에 적용하지 않는다.
