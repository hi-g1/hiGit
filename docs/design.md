# 디자인 규칙 (Design)

방향: **담백하고 깔끔하게.** 회색 계열 바탕, 포인트 색은 차분한 파란색 하나. 그림자·그라데이션·이모지·과한 둥근 모서리를 쓰지 않는다. "AI가 만든 템플릿" 느낌의 원인(보라-파랑 그라데이션, 큰 카드 그림자, 의미 없는 아이콘 남발, 모든 곳에 둥근 배지)을 피한다.

## 색 토큰
`src/styles/tokens.css`에 CSS 변수로 둔다. 화면 코드에 색 값을 직접 쓰지 않는다. 대비는 모두 WCAG AA(본문 4.5:1) 이상으로 계산해 두었다.

| 토큰 | 라이트 | 다크 | 쓰임 |
| --- | --- | --- | --- |
| `--bg` | `#F7F7F5` | `#18191B` | 앱 바탕 |
| `--surface` | `#FFFFFF` | `#1F2023` | 패널, 목록 |
| `--surface-hover` | `#F0F0EE` | `#26272B` | 행 호버 |
| `--border` | `#E4E4E1` | `#2E3034` | 구분선 (1px) |
| `--text` | `#1F2328` | `#E6E6E3` | 본문 |
| `--text-muted` | `#6B6F76` | `#9A9DA3` | 보조 글, 시각, 해시 |
| `--accent` | `#3A6EA5` | `#7FA7D6` | 주 버튼, 선택, 현재 갈래 |
| `--accent-text` | `#FFFFFF` | `#18191B` | 주 버튼 글자 |
| `--added` | `#2F7D4F` | `#6BBF8A` | 추가된 파일·줄 |
| `--modified` | `#9A6110` | `#D9A54A` | 수정된 파일 |
| `--deleted` | `#B4423A` | `#E07A70` | 삭제된 파일·줄, 위험 작업 |
| `--diff-add-bg` | `#EAF5EE` | `#1E2E24` | 비교 화면 추가 줄 배경 |
| `--diff-del-bg` | `#FBECEA` | `#33201F` | 비교 화면 삭제 줄 배경 |

갈래 그래프 선 색은 채도를 낮춘 6색을 순서대로 쓴다: `#3A6EA5`, `#2F7D4F`, `#9A6110`, `#7A5BA6`, `#2E7F86`, `#8A5A44`. 현재 갈래만 `--accent`.

## 글꼴
- 본문: **Pretendard** (한글·영문 균형, OFL 라이선스, npm 패키지로 앱에 포함, D-014). 대체: `system-ui`.
- 코드·해시·파일 경로: **JetBrains Mono** (OFL, latin 부분만 포함, D-014). 대체: `ui-monospace`.
- 크기: 13px(기본), 12px(보조), 15px(화면 제목), 20px(홈 제목). 줄 간격 1.5.
- 굵기는 400과 600 두 가지만. JetBrains Mono는 400만 포함한다(D-014).

## 간격과 모양
- 간격 단위 4px: 4, 8, 12, 16, 24, 32.
- 모서리: 버튼·입력 6px, 패널 8px. 원형은 아바타만.
- 그림자: 떠 있는 것(메뉴, 대화상자, 툴팁)에만 `0 4px 16px rgba(0,0,0,.08)`.
- 아이콘: Lucide, 16px, 선 굵기 1.5. 글자 없이 아이콘만 있는 버튼에는 반드시 툴팁.

## 부품 규칙
- **버튼**: 화면마다 주 버튼(`--accent` 채움)은 하나. 나머지는 테두리 버튼 또는 글자 버튼.
- **위험 버튼**: `danger` 액션은 글자색 `--deleted` 테두리 버튼, 확인 대화상자에서만 채움.
- **Term 툴팁**: 지연 400ms, 위쪽 우선. 내용 세 줄: 원래 이름(600) · 명령(모노) · 설명(muted).
- **목록 행**: 높이 32px, 호버 시 `--surface-hover`, 선택 시 왼쪽 2px `--accent` 막대.
- **빈 상태**: 그림 대신 한 줄 설명과 버튼 하나.
- **움직임**: 150ms ease-out, 페이드와 4px 이동만. `prefers-reduced-motion`이면 끈다.

## 다크 모드
시스템 설정을 따르고 설정에서 라이트/다크/시스템 선택. 토큰만 바꾸고 부품 코드는 같다.

## 확인 사항
- Windows(WebView2)와 Ubuntu(WebKitGTK)에서 글꼴 렌더링과 스크롤바 모양을 매번 비교한다. 스크롤바는 CSS로 얇게 통일.
- 한글 입력: 저장 메시지 입력창에서 조합 중 Enter가 저장을 실행하지 않게 `isComposing`을 확인한다.
