hiGit guide

hiGit lets you save, compare and undo versions of your files without knowing Git. Hover a word on the screen to see the original Git name. The Korean guide has screenshots for each chapter.

1. Install

hiGit uses the Git installed on your computer. If Git is missing, the app tells you where to get it.

  1. Windows: install Git for Windows, then run hiGit_version_x64-setup.exe. It installs for your user only, without an admin prompt. If "Windows protected your PC" appears, choose More info and then Run anyway; this pre-release is not signed yet.
  2. Ubuntu: run sudo apt install ./hiGit_version_amd64.deb, which also installs Git. The AppImage needs libfuse2 and Git.

2. First start, name and email

Every saved version records who saved it. Set your name and email once on the start screen; you can change them later in Settings, General. Connecting GitHub can wait.

3. Open a folder or clone

  1. Choose Open folder or press Ctrl+O. A folder that is not under version control yet offers Start version controlinit, which keeps your files and starts recording.
  2. To get a repository from GitHub, choose Cloneclone or press Ctrl+Shift+O.
  3. The app reopens your last project. Use the project name at the top left to switch. With the installed app you can also right-click a folder and choose Manage with Git.

4. Save a version

  1. Changed files are listed under Changesstatus.
  2. Check the files to include in versionstage; if none are checked, all are included.
  3. Describe what you did and choose Save versioncommit or press Ctrl+Enter. The notice offers undo, or press Ctrl+Z.

5. Compare

Select a file to see Comparediff: green lines were added, red lines removed, with + and − signs. Unchanged lines are folded; click to expand. Turn on line wrap for long lines. Right-click a file for Show in folder, Open with default app, Copy path and Discard changes. Files that can run are not opened with the default app.

6. Version history

Choose Version historylog or press Ctrl+H; Esc goes back. Branches are lines and versions are stations. Click a station for a menu: view files at that time, go back to it, undo it, or start a new branch there.

7. Undo and activity

Most actions can be undone with Ctrl+Z and redone with Ctrl+Shift+Z. For older work open Activityreflog (Ctrl+Shift+H) and choose Go back to this point; your changed files stay. Versions you already uploaded are undone with a new version instead of being removed.

8. Branches

A branchbranch is a separate line of work. Click the branch name or press Ctrl+B, type a new name and choose To a new branch. Choosing another branch switches to it; if you have changed files, the app asks whether to move them to a new branch or leave them here.

9. Combine and conflicts

Combinemerge brings work from another branch. When both changed the same lines, the conflict screen asks one place at a time: your branch, the incoming branch, both, or edit by hand. The preview below updates at once. When every place is chosen, finish; you can always cancel. Keys 1 2 3 choose and Ctrl+↑ Ctrl+↓ move. Your choices survive a restart.

10. Set aside

Set asidestash at the bottom of Home puts your changes away and restores the last version. Take them out again from Activity. "Leave here" when switching branches works the same way for that branch.

11. GitHub and sync

In Settings, GitHub, choose Connect and enter the shown code in your browser. Syncsync gets new versions and then uploads yours; the ↑ number is how many will be uploaded. Projects without a remote can be published as a new GitHub repository. The app quietly checks the remote every few minutes.

12. Review requests

For projects with a GitHub remote, Review requestPull Request lists requests and lets you create one, read checks and comments, comment and combine.

13. Settings

General: name and email, text size, language, appearance, term tips, folder right-click menu, first-time tips. GitHub: connection. Advanced: Git location, log folder, rewriting uploaded versions. About: this guide and open source licenses. Ctrl+= and Ctrl+- change the text size.

14. Keyboard shortcuts

Press Ctrl+/ anywhere for the full list, and Ctrl+K to find any action by name.

15. FAQ

A window asks "Trust and open" or "Open with them turned off".
The project has settings that run programs or change where it uploads. If you don't know where it came from, open with them turned off; such settings don't run, and sync is disabled when upload targets were changed.
Undo says it can't.
Git was used outside the app or the version was already uploaded. Find the earlier state in Activity.
Where are my versions?
Inside the project folder. Uninstalling hiGit keeps your projects and history.
Where do I report problems?
Open an issue in the repository. For security problems use the private report described in SECURITY.md.
