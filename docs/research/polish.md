# 다듬기

- 날짜: 2026-10-16
- 바탕: 사용자가 Ubuntu에서 홈 화면을 써 보고 낸 의견 네 가지와, 그 스크린샷을 점검해서 찾은 것.

## 1. 글자 크기
지금 본문 13px은 두 OS 모두에서 작다. Ubuntu 기본 글꼴은 11pt, 약 15px이고 Windows 기본 UI 글자는 DPI 배율을 적용하면 14px 안팎이다.

- 크기 토큰을 바꾼다. 보조 12→13, 본문 13→14, 화면 제목 15→17, 버전 이름 칸 20→22, 시작 화면 이름 26→28, 코드 13→14. 12px보다 작은 글자는 없앤다.
- OS 기본값을 따른다. Windows는 본문 14px, Ubuntu는 15px에서 시작한다.
- OS의 글자 배율을 따른다. Windows는 접근성 설정의 텍스트 크기, Ubuntu는 `org.gnome.desktop.interface text-scaling-factor`. 웹뷰가 이 값을 스스로 반영하지 않으므로 `crates/platform`에서 읽어 루트 글자 크기에 곱한다.
- 설정에 "글자 크기"를 둔다. 작게, 보통, 크게, 아주 크게. 단축키 Ctrl+=, Ctrl+-, Ctrl+0도 같은 값을 바꾼다.
- 모든 크기 토큰을 루트 글자 크기 기준 단위로 바꿔 한 곳만 바꾸면 화면 전체가 같이 커지게 한다. 행 높이, 노선도 역 크기, 아이콘도 함께 커진다.
- 800px 너비와 "아주 크게"에서 상단 바가 넘치지 않는지 테스트한다.

## 2. 언어 설정
`src/messages`와 `src/glossary`에 ko, en이 이미 있고 `useUiStore`에 locale이 있다. 고를 곳만 없다.

- 설정에 "언어": 시스템 따라가기, 한국어, English. 고르면 다시 시작하지 않고 바로 바뀐다. 앱 데이터에 저장한다.
- 시스템 따라가기는 OS 언어가 한국어면 한국어, 그 밖은 English.
- 버전 이름 제안, 날짜, "3분 전" 같은 상대 시각도 앱 언어를 따른다.
- English에서 Term 툴팁은 화면 이름과 원래 이름이 같으면 이름 줄을 빼고 명령과 설명만 보인다.
- 두 언어 모두에서 화면 문구가 빠진 곳이 없는지 테스트한다. 키가 한쪽에만 있으면 실패하게.

## 3. 밑줄 줄이기
스크린샷에서 밑줄이 동기화, 검토 요청, 버전 기록, 작업 내역, 버전 저장 버튼 글자, 임시 보관, 고친 것 버리기에 모두 있다. 대부분 `src/ui/Term.module.css`의 점선 밑줄이고, 일부는 Toast와 History의 `text-decoration: underline`이다.

- Term은 밑줄 없이 툴팁만 뜬다. 지연은 400ms에서 600ms로 늘린다.
- 버튼과 상단 바 안의 글자에는 어떤 표시도 하지 않는다. 글자 버튼은 호버하면 `--surface-hover` 바탕으로 알린다.
- 밑줄은 문장 속 링크에만, 그것도 호버할 때만 쓴다.
- 용어 설명을 끌 수 있게 설정에 "용어 설명 보기"를 둔다. 기본은 켬.
- 린트로 막는다. `text-decoration: underline`과 `border-bottom: dotted`는 정해 둔 링크 부품 밖에서 쓰지 못하게.

## 4. 노선도의 "…"
`src/features/history/layout/horizontal.ts` 198줄이 접힌 앞쪽 역을 선 위에 "…" 글자로 그린다. 선과 겹쳐서 잘못 그려진 것처럼 보인다.

- "…" 글자를 없앤다. 선의 왼쪽 끝 24px를 `--border-strong` 점선으로 바꿔 앞에 더 있다는 것만 보인다.
- 왼쪽 끝 아래에 12px `--text-muted`로 "이전 24개"를 쓰고, 누르면 버전 기록을 연다.
- 역 이름표가 "core: keep the ..."처럼 너무 짧게 잘린다. 홈 노선도의 역은 5개까지만 그리고, 역 사이 간격을 이름표 폭에 맞춰 넓힌다. 호버와 키보드 포커스에는 전체 이름 툴팁.
- 지금은 노선도가 창의 왼쪽 절반만 쓴다. "지금 여기"를 합치기 제안 블록 앞까지 오른쪽으로 보내 폭을 다 쓴다.
- "지금 여기"는 design.md대로 `--primary` 바탕 작은 이름표로 한다. 스크린샷에서는 글자만 있다.
- 비교 칸의 접힌 줄도 "…"만 보인다. `src/features/diff/DiffView.tsx` 43줄이다. 그림대로 "변경 없는 12줄 · 펼치기"로 쓴다.

## 5. 스크린샷에서 더 찾은 것
- 고친 파일 체크 상자가 모두 비어 있어서 아무것도 안 들어가는 것처럼 보인다. D-062대로 index는 건드리지 않되, 넣은 파일이 0개이면 화면에는 모든 체크를 켠 모양으로 보이게 한다. 이때 하나를 끄면 나머지를 넣는다. 그림 r-home.png와 같은 모습이다.
- 파일 줄이 경로 한 줄이라 "docs/plans/010-settings-g..."처럼 잘린다. 그림처럼 위에 파일 이름, 아래에 폴더를 12px `--text-muted`로 쓴다.
- 파일 상태는 "수정"인데 버전 이름 제안은 "고침"이다. 한 낱말로 맞춘다. 그림과 버전 이름 제안이 "고침"이니 "고침"을 추천한다.
- 브랜치 단추만 테두리 상자가 있고 프로젝트 이름은 없다. 둘 다 테두리 없이 두고 호버하면 바탕이 생기게 맞춘다.
- 비교 칸에서 긴 줄이 오른쪽에서 잘리고, 가로 스크롤 막대가 맨 아래에만 있어 찾기 어렵다. 비교 칸 머리에 "줄 바꿈" 켬과 끔을 두고, 기본은 켬.
- home.zip 같은 압축 파일과 실행 파일을 버전에 넣으려 하면 비밀 파일 알림 줄과 같은 꼴로 한 번 알린다. 막지는 않는다.

## 6. 그 밖의 디테일
- 화면 모드: 설정에 시스템 따라가기, 라이트, 다크.
- 창: 크기와 위치를 기억한다. 최소 크기 960x600. 모니터를 옮겨도 배율이 맞게.
- 시각 표시: 1시간 안은 "N분 전", 오늘은 "오후 3:12", 올해는 "10월 7일", 그 전은 "2025년 10월 7일". 호버하면 정확한 시각.
- 긴 이름은 모두 끝을 말줄임하고 호버하면 전체가 보인다. 파일 경로는 앞을 줄인다.
- 불러오는 표시는 300ms가 넘을 때만 보인다. 짧은 작업에서 깜빡이지 않게.
- 파일 줄의 마우스 오른쪽 메뉴: 폴더에서 보기, 경로 복사, 이 파일 고친 것 버리기. 더블클릭하면 기본 앱으로 연다.
- 포커스 테두리는 모든 컨트롤에서 같은 `--accent` 2px. Tab 순서는 상단 바, 노선도, 이름 칸, 파일 목록, 비교 칸.
- 스크롤 막대는 OS 모양을 따르되 비교 칸과 목록에서 같은 폭.
- 설정 대화상자 구역: 일반은 언어, 글자 크기, 화면 모드, 용어 설명 보기. GitHub. 고급은 Git 위치, 로그 폴더 열기.
