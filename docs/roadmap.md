# 로드맵

짧은 반복으로 진행한다. 반복마다 "동작하는 앱"이 남아야 한다. 범위는 반복을 마칠 때마다 다시 정한다. 각 반복의 상세 계획은 `planner`가 `docs/plans/`에 쓴다.

## 반복 0: 뼈대
- Tauri 2 + React + TS 프로젝트, Rust 워크스페이스(app, core, git, hosting, platform, watcher).
- `GitBackend` 트레이트와 `CliBackend`의 status, log만.
- `Action` 레지스트리, 실행기, 조회용 Query, `Term` 부품과 glossary(ko, en), 디자인 토큰.
- 저장 기록은 단순 목록(노선도는 아래 "노선도 보기").
- 첫 실제 Action: 관리 시작(init). 저장소가 아닌 폴더를 열면 안내 문구 옆 "관리 시작" 버튼.
- Windows·Ubuntu CI(빌드 + 테스트).
- 완료 기준: 폴더를 열면 바뀐 파일 목록과 저장 기록이 보이고, 용어에 호버하면 원래 이름이 뜬다.

## 반복 1a: 기반과 내 컴퓨터 안의 작업
- 기반: 타입 있는 액션 입력(D-020), 저장소 git hook(D-022), CI Windows artifact(crt-static).
- 저장에 넣기·빼기, 저장하기, 비교 보기.
- 파일 변경 감시(.gitignore 대상 제외, 실패 시 창 포커스 새로 고침), 상단 상태 표시.

## 반복 1b: 갈래와 원격
- 작업 갈래 만들기·바꾸기, 받기·올리기, 새 소식 확인(SSH 질문 끄기, D-023).

## 반복 2: 합치기와 안전망
- 합치기(미리보기, 끌어놓기), 충돌 해결 화면, 잠시 치워두기, 변경 취소.
- 백업 참조, UndoJournal, "방금 작업 취소", 안전망 화면.

## 반복 3: 기록 다루기
- 방금 저장 고치기, 기록 남기고 취소, 기록째 되돌리기, 기록 정리하기, 저장 하나만 가져오기, 버전 표시.

## 반복 4: GitHub
- 로그인(device flow), 검토 요청 목록·만들기, 프로젝트 가져오기.

## 반복 5: OS 통합과 배포
- 폴더 우클릭 메뉴(Windows, Nautilus), 단일 인스턴스, 설치 파일(.msi, .deb, AppImage).

## 따로 둔 항목: 저장 기록 노선도 보기
- 시기 미정. D-017(제안)이 확정되면 반복 사이에 배치한다. 반복 1 이후 아무 때나 넣을 수 있다.
- 노선도 + 확대·축소 + 선 굵기로 저장 기록 그리기(`docs/research/git-visualization.md` "추천 조합").
- `docs/architecture.md` "저장 기록 그리기 계층"대로 배치 계산과 그리기를 나누고 SVG로 시작한다.
- 세이브 카드(안전망)는 반복 2, 카드 지도(기록 정리)는 반복 3의 해당 화면에서 같은 결정을 따른다.
